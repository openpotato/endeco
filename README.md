# Encoder / Decoder

A small, dependency-free encoder and decoder toolbox that runs entirely in your browser.

It provides common web, text and data conversions in a single minimal interface. No input is uploaded or transmitted.

## Features

+ URL component encoding and decoding
+ Whole URL / URI encoding and decoding
+ Query string ↔ JSON conversion
+ Base64 encoding and decoding
+ Base64URL encoding and decoding
+ Base32 encoding and decoding
+ Base16 / UTF-8 hexadecimal encoding and decoding
+ HTML character escaping and decoding
+ JSON string escaping and decoding
+ JavaScript Unicode escaping and decoding
+ JWT header and payload inspection
+ Unix timestamp conversion in seconds
+ Unix timestamp conversion in milliseconds
+ Copy, swap and clear actions
+ Responsive layout
+ No dependencies
+ No build step
+ Runs completely locally in the browser

## Privacy

All processing happens locally in the browser.

The application has no backend, sends no requests containing your input, and requires no analytics or external libraries.
